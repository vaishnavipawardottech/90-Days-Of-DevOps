## 4. Mini Troubleshooting Flow

If a service is not working, I can follow these basic troubleshooting steps.

### Step 1 – Check Service Status

```bash
systemctl status <service>
```

Check whether the service is running, stopped, or failed.

### Step 2 – Check Service Logs

```bash
journalctl -u <service> -n 20
```

Check the recent logs for errors or useful information.

### Step 3 – Check the Process

```bash
pgrep -a <process>
```

Check whether the process related to the service is running.

### Step 4 – Check Recent Logs

```bash
journalctl -u <service> --since "10 minutes ago"
```

Check for any recent errors or events.

### Basic Troubleshooting Flow

```text
Service Status
      ↓
Check Logs
      ↓
Check Process
      ↓
Identify the Problem
```

## 5. What I Learned

- `ps` can be used to check running processes.
- `systemctl` can be used to inspect systemd services.
- `journalctl` can be used to check service logs.
- Checking the service status, logs, and process helps with basic Linux troubleshooting.
